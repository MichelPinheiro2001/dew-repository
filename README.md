# 🌐 Desenvolvimento Web (DEW) - Univille

Repositório oficial para entrega e versionamento dos códigos e atividades desenvolvidas nas aulas de **Desenvolvimento Web (DEW)** da [Univille](https://www.univille.br/), ministradas pela professora **Sabrina Boing Moreira**.

---

## 🛠️ Ferramentas Utilizadas

* **HTML5 e CSS3** - Linguagens base para estruturação e estilização das páginas web.
* **VS Code** - Editor de código utilizado para o desenvolvimento das páginas.
* **Git** - Sistema de controle de versão utilizado para realizar os commits e envios para o GitHub.

---

## 📂 Organização do Repositório

Atualmente, o repositório foca nos conceitos iniciais de introdução ao HTML e CSS. 

*Conforme a matéria for evoluindo e novos conteúdos forem abordados (como novas tags, estilizações avançadas, etc.), novas pastas e estruturas serão adicionadas a este repositório para organizar as entregas e atividades.*

---

## 🚀 Como Visualizar

1. Navegue pelas pastas do repositório para encontrar o arquivo ou atividade desejada (geralmente arquivos `index.html` acompanhados de seus arquivos `.css`).
2. Você pode clonar o repositório ou abrir os arquivos diretamente no seu navegador ou editor de código (VS Code) para testar o resultado.
